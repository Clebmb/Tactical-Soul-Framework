# Three-room art route

Run `TacticalSoul.cmd play examples/three-room-art/mod.json` from the framework
root. The neon hallway leads through an original-art gallery mural to the
contrasting save room. Read `docs/THREE-ROOM-ART.md` for permissions, native
evidence, capture limitations and displaced neighboring door links.

Artwork JSON is original MIT procedural example data. No original game is
included. This is a local route demonstration, not a complete campaign.
