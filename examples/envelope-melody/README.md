# Original envelope authoring

Run `TacticalSoul.cmd play examples/envelope-melody/project.json`.
Generated original sine uses attack8/decay240/sustain160/release160,
with a48-tick gate and96-tick step. Flat mod.json builds identical bytes.
No commercial audio assets. Values are native bytes, not milliseconds.
See docs/MUSIC-SAMPLES.md for inheritance, bounds and native evidence limits.
