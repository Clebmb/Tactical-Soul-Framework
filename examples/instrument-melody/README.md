# Original instrument switching

Run `TacticalSoul.cmd play examples/instrument-melody/project.json`.
Original MIT40-sample triangle and square cycles alternate on one boot track.
Both WAVs are mono unsigned8-bit at8000Hz (200Hz source pitch), loop0.
The flat mod.json produces identical bytes. See docs/MUSIC-SAMPLES.md for
budgets, source ownership, native evidence and remaining limits.
