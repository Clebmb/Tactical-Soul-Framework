# Named native content workshop

Run `TacticalSoul.cmd play examples/named-content-workshop/mod.json` from the framework folder. Finish opening dialogue, Start, Down, A opens Equipment with original custom checker patterns. Item Use is Down twice from the first pause option; an owned item such as Potion is needed to expose its icon.

All three native icon pages and their shared palette are replaced through stable target names, preserving native headers. page-0.json, page-1.json and page-2.json contain original 128x128 indexed patterns. palette.json contains seven repeated original 16-color banks. Artwork is MIT. Item identities, names, effects and native animations are unchanged.

Read docs/RESOURCE-AUTHORING.md for exact contracts, native evidence and extension guidance. The native verifier uses an identical one-Potion ownership fixture for baseline/custom captures; the mod itself does not grant items. This example demonstrates resource loading, not attractive final icon design or a complete sprite importer.
