# Original boot melody

Run `TacticalSoul.cmd play examples/boot-melody/mod.json` from the framework root.
The four-note original sine melody replaces only the registered boot-song slot,
plays once and settles to silence. Edit the checked note list in mod.json.
See [contracts and native evidence](../../docs/BOOT-MELODY.md).
No external assets, compiler or custom RAM are required. Gameplay music and
save/transition behavior are outside this example's certified scope.
