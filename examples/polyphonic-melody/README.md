# Original two-track harmony

Run `TacticalSoul.cmd play examples/polyphonic-melody/project.json`.
Two original generated sine voices play MIDI60 and67 simultaneously, with
48-tick gates and96-tick steps. Flat mod.json produces identical bytes.
No extracted audio assets. See docs/BOOT-MELODY.md for timing/resource limits,
release-tail overlap and native evidence boundaries.
