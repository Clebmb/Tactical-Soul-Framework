# Two-room art example

Run `TacticalSoul.cmd play examples/two-room-art/mod.json` from the framework root.
The hallway keeps the original neon step; the connected save room displays an
original contrasting non-solid mural. Read `docs/TWO-ROOM-ART.md` for exact scope,
source provenance, native lifecycle tests and limits before extending this mod.
Artwork JSON is original MIT example data; original game content is not included.
