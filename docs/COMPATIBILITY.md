# Tactical Soul Framework compatibility

Required: Castlevania: Aria of Sorrow, GBA USA revision 0, 8,388,608 bytes.
SHA-256: `910f88d3701e6c9f99c0d63660c14c61d8b79b0c17bfd7b35a15185be36430a5`.
Header CASTLEVANIA2, game code A2CE, revision 0. Only this profile is supported.
Tactical Soul Framework does not require a Mario ROM. Companion hashes elsewhere in the shared
research documents concern the independent Mario example. Different regional/
revision images require a new audited profile, never a relaxed hash check.
